# 講座 87　空の関門：テクノロジ総合

## 物語

関の第一扉。テクノロジの空気だけが濃い。
トリス: 「技の試練だ。空を裂くには基礎から証明せよ。」

## 分野

午前・総合演習

## 今日の用語

これまで学んだ **テクノロジ分野** の総復習です。

- 基礎理論（ビット・論理・計算量）
- アルゴリズム（探索・ソート・データ構造）
- ハードウェア（CPU・メモリ・入出力）
- ソフトウェア（OS・仮想記憶・コンパイラ）
- データベース（SQL・正規化・トランザクション）
- ネットワーク（OSI・TCP/IP・DNS）
- セキュリティ（暗号・認証・攻撃と対策）
