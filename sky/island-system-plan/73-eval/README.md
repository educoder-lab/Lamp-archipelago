## 今日の用語

| 用語 | 意味 |
|------|------|
| **ROI（投資利益率）** | 利益 ÷ 投資額 × 100 で投資効果を測る指標 |
| **TCO（総所有コスト）** | 導入から廃棄まで全期間の総コスト |
| **EA（エンタープライズアーキテクチャ）** | 組織全体の業務と IT を 4 つの体系で設計する手法 |
| **共通フレーム** | ソフトウェアライフサイクルの標準プロセス体系（JIS X 0160） |
