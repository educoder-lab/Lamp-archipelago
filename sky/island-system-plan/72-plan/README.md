# 講座 72　システム企画と要件定義

## 物語

講座 **72** 企画港に「システム企画と要件定義」の封印がある。
要件の潮が港に打ち寄せる。設計士ナギ が待っている。

## 分野

ストラテジ・システム企画

## 今日の用語

| 用語 | 意味 |
|------|------|
| **システム化計画** | 経営課題を解決する IT 投資の方針と優先度を決める活動 |
| **要件定義** | システムに求められる機能・性能を明確にする工程 |
| **機能要件** | システムが実現すべき処理や入出力 |
| **非機能要件** | 性能・信頼性・セキュリティなどの品質要件 |
| **フィジビリティスタディ** | プロジェクトの実現可能性を事前に検証する調査 |
