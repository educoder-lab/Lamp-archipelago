# 講座 83　ITサービスマネジメント

## 物語

講座 **83** 灯火番小屋に「ITサービスマネジメント」の封印がある。
障害の警笛が遠くで鳴る。灯火番イズミ が待っている。

## 分野

マネジメント・サービスマネジメント

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ITIL** | IT サービスマネジメントのベストプラクティス集 |
| **SLA** | サービス提供者と利用者の間で合意した品質水準 |
| **インシデント管理** | サービスの中断を速やかに復旧する活動 |
| **問題管理** | インシデントの根本原因を特定・解消する活動 |
| **変更管理** | 変更によるリスクを最小化する管理プロセス |
