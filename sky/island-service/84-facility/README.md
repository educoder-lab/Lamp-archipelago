# 講座 84　ファシリティマネジメント

## 分野

マネジメント・サービスマネジメント

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ファシリティマネジメント** | コンピュータ室・電源・空調など設備を管理する活動 |
| **UPS（無停電電源装置）** | 停電時に一時的に電力を供給する装置 |
| **サーバルーム** | サーバ設置のための温度・湿度管理された部屋 |
| **BCP（事業継続計画）** | 災害時に事業を継続・早期復旧するための計画 |
| **DR（ディザスタリカバリ）** | 災害からの IT システム復旧策 |
