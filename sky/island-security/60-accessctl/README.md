## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **アクセス制御** | 利用者ごとに情報資源への操作を制限する仕組み |
| **任意アクセス制御 (DAC)** | 所有者が自由に権限を設定できる方式 |
| **強制アクセス制御 (MAC)** | システムが機密レベルで強制的に制御する方式 |
| **RBAC（ロールベースアクセス制御）** | 役割（ロール）を通じて権限を付与する方式 |
| **SSO（シングルサインオン）** | 一度の認証で複数システムを利用可能にする仕組み |
