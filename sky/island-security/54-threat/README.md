# 講座 54　脅威と攻撃手法

脅威の影が商会の灯を試す。盾商会マスター・クレス が待っている。

## 今日の用語

| 用語 | 意味 |
|------|------|
| **マルウェア** | 悪意あるソフトウェアの総称（ウイルス・ワーム・トロイの木馬など） |
| **フィッシング** | 偽サイトに誘導して個人情報を騙し取る攻撃 |
| **DoS 攻撃** | 大量リクエストでサービスを妨害する攻撃 |
| **ソーシャルエンジニアリング** | 人間の心理的弱点を突いて情報を入手する手法 |
