# 講座 61　インシデント対応と法規

## 物語

講座 **61** 盾商会に「インシデント対応と法規」の封印がある。
脅威の影が商会の灯を試す。盾商会マスター・クレス が待っている。

## 分野

テクノロジ・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **インシデント対応** | セキュリティ事故の検知・封じ込め・復旧・再発防止の一連の活動 |
| **CSIRT** | セキュリティインシデントに対応する組織内チーム |
| **個人情報保護法** | 個人情報の取扱いに関する日本の法律 |
| **不正アクセス禁止法** | 他人のID・パスワードで不正ログインすることを禁じる法律 |
