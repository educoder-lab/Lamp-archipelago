## 分野

テクノロジ・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **SQLインジェクション** | SQL文を不正に挿入してDBを操作する攻撃 |
| **XSS（クロスサイトスクリプティング）** | 悪意あるスクリプトをWebページに埋め込む攻撃 |
| **CSRF** | ログイン済みユーザに意図しない操作をさせる攻撃 |
| **ディレクトリトラバーサル** | パス操作で非公開ファイルにアクセスする攻撃 |
