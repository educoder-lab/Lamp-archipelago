# 講座 56　認証と証明書

## 物語

講座 **56** 盾商会に「認証と証明書」の封印がある。
脅威の影が商会の灯を試す。盾商会マスター・クレス が待っている。

## 分野

テクノロジ・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **認証局 (CA)** | デジタル証明書を発行し公開鍵の正当性を保証する機関 |
| **PKI（公開鍵基盤）** | 認証局を核として公開鍵を管理する仕組み |
| **SSL/TLS** | 通信を暗号化し、証明書で相手を認証するプロトコル |
| **多要素認証 (MFA)** | 知識・所持・生体の 2 つ以上を組み合わせた認証 |
