# 講座 57　ファイアウォールとDMZ

## 分野

テクノロジ・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ファイアウォール** | ネットワーク境界で不正アクセスを遮断する装置・ソフト |
| **パケットフィルタリング** | IPアドレス・ポート番号でパケットの通過を制御する方式 |
| **DMZ（非武装地帯）** | 外部と内部の間に置く中間ネットワーク。公開サーバを配置 |
| **IDS/IPS** | 侵入を検知(IDS)・防止(IPS)するシステム |
| **WAF** | Web アプリケーションへの攻撃を防ぐファイアウォール |
