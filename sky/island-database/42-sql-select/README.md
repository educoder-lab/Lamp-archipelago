# 講座 42　SQL SELECT文

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **SELECT** | テーブルからデータを取得する SQL 文 |
| **WHERE** | 条件を指定して行を絞り込む句 |
| **ORDER BY** | 結果を指定列で並べ替える句 |
| **DISTINCT** | 重複行を除外するキーワード |
| **LIKE** | パターンマッチングに使う演算子。% は任意文字列 |
