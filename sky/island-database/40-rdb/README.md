# 講座 40　関係データベースの基礎

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **関係データベース (RDB)** | データを表（テーブル）で管理するデータベース |
| **テーブル（表）** | 行（レコード）と列（カラム）で構成されるデータの集合 |
| **主キー** | 行を一意に識別する列。NULL 不可 |
| **外部キー** | 他テーブルの主キーを参照する列。参照整合性を保つ |
