# 講座 46　E-R図と概念設計

## 物語

講座 **46** 水晶の泉に「E-R図と概念設計」の封印がある。
関係の水脈が泉底でつながる。水晶司ライラ が待っている。

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **E-R 図** | エンティティ（実体）とリレーションシップ（関連）でデータ構造を表す図 |
| **エンティティ** | 管理対象となる「もの」（顧客、商品など） |
| **属性（アトリビュート）** | エンティティが持つデータ項目 |
| **カーディナリティ** | 1対1、1対多、多対多などの関連の多重度 |
