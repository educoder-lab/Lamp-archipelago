# 講座 43　SQL 結合と副問合せ

## 物語

講座 **43** 水晶の泉に「SQL 結合と副問合せ」の封印がある。
関係の水脈が泉底でつながる。水晶司ライラ が待っている。

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **内部結合 (INNER JOIN)** | 両テーブルで一致する行だけを返す |
| **外部結合 (OUTER JOIN)** | 一致しない行も NULL で返す |
| **副問合せ（サブクエリ）** | SQL 文の中に入れ子にした SELECT 文 |
| **GROUP BY** | 指定列でグループ化し集約関数を適用する |
| **HAVING** | GROUP BY の結果をさらに絞り込む句 |
