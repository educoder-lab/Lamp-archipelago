# 講座 41　正規化

## 物語

講座 **41** 水晶の泉に「正規化」の封印がある。
関係の水脈が泉底でつながる。水晶司ライラ が待っている。

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **正規化** | データの冗長性を排除しテーブルを分割する設計手法 |
| **第1正規形** | 繰返し項目を除去し、すべての列が原子的な値を持つ |
| **第2正規形** | 部分関数従属を除去し、主キー全体に完全関数従属させる |
| **第3正規形** | 推移的関数従属を除去する |
