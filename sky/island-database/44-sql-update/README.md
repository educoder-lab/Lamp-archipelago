# 講座 44　SQL 更新系と制約

## 分野

テクノロジ・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **INSERT** | テーブルに行を追加する SQL 文 |
| **UPDATE** | テーブルの既存行を更新する SQL 文 |
| **DELETE** | テーブルから行を削除する SQL 文 |
| **NOT NULL 制約** | 列に NULL を許さない制約 |
| **CHECK 制約** | 列の値が条件を満たすことを保証する制約 |
