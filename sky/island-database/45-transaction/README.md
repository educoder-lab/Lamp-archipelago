# 講座 45　トランザクションと障害回復

## 物語

講座 **45** 水晶の泉に「トランザクションと障害回復」の封印がある。
関係の水脈が泉底でつながる。水晶司ライラ が待っている。

## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **トランザクション** | 一連の処理をまとめた不可分な単位 |
| **ACID 特性** | 原子性・一貫性・独立性・永続性 |
| **コミット** | トランザクションの結果を確定する操作 |
| **ロールバック** | トランザクションの結果を取消して元に戻す操作 |
