## 今日の用語

| 用語 | 意味 |
|------|------|
| **ラスタ画像** | ピクセルの集合で表す画像（BMP, JPEG, PNG） |
| **ベクタ画像** | 数式で図形を定義する画像（SVG）。拡大しても劣化しない |
| **標本化（サンプリング）** | アナログ信号を一定間隔で値を取り出しデジタル化する工程 |
| **量子化** | 標本化した値を有限ビットで近似する工程 |
| **データ圧縮** | 可逆（元に戻せる）と非可逆（情報を捨てる）がある |
