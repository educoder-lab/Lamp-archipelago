# 講座 31　仮想化とクラウド

## 物語

講座 **31** 系譜の館に「仮想化とクラウド」の封印がある。
信頼性の釣り合いが館を支える。系譜士セラ が待っている。

## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **仮想化** | 物理資源を論理的に分割・統合する技術 |
| **ハイパーバイザ** | 仮想マシンを管理するソフトウェア層 |
| **IaaS** | インフラ（サーバ・ネットワーク等）をクラウドで提供 |
| **PaaS** | 開発実行環境をクラウドで提供 |
| **SaaS** | ソフトウェアをクラウドで提供 |
