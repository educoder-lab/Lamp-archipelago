## 分野

テクノロジ・システム構成

## 今日の用語

| 用語 | 意味 | 覚え方・総称 |
|------|------|----------------|
| **仮想化** | 物理資源を論理的に分割・統合する技術 | 1 台の実機を「仮想の PC」に分ける |
| **ハイパーバイザ** | 仮想マシンを管理するソフトウェア層 | VM の管理人 |
| **クラウド** | ネット越しに計算機資源を借りる使い方 | 自家発電せず電力を買うイメージ |
| **IaaS** | インフラ（サーバ・ネットワーク等）をクラウドで提供 | Infrastructure as a Service／基盤を借りる |
| **PaaS** | 開発実行環境をクラウドで提供 | Platform as a Service／土台を借りる |
| **SaaS** | ソフトウェアをクラウドで提供 | Software as a Service／ソフトを借りる |

## 身近なたとえ → 現場の実例

- **仮想化**: ビルのテナント分け → 社内で会計用・Web 用・テスト用の VM を同じ実機上に同居させる。
- **クラウド**: 電力会社から電気を買う → 公開前だけサーバを借りて負荷試験し、終わったら止めて従量課金。
- **IaaS**: テント枠だけ借りる → OS とアプリは自分で入れる仮想サーバ。
- **PaaS**: 厨房まで借りる → コードを載せるだけで動く実行基盤。
- **SaaS**: 学食の定食 → ブラウザで使う業務メールや表計算。
