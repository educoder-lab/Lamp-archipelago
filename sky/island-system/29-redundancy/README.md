# 講座 29　冗長化と多重化

## 物語

講座 **29** 系譜の館に「冗長化と多重化」の封印がある。
信頼性の釣り合いが館を支える。系譜士セラ が待っている。

## 分野

テクノロジ・システム構成

## 今日の用語

| 用語 | 意味 |
|------|------|
| **デュプレックスシステム** | 現用系と待機系の 2 系統で構成 |
| **デュアルシステム** | 2 系統が同時に同じ処理を行い結果を照合 |
| **ホットスタンバイ** | 待機系が稼働状態で即座に切替え可能 |
| **コールドスタンバイ** | 待機系は停止状態。障害時に起動する |
| **直列・並列の稼働率** | 直列=積、並列=1-(1-A)(1-B) |
