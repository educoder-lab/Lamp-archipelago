## 今日の用語

| 用語 | 意味 |
|------|------|
| **スループット** | 単位時間あたりの処理量 |
| **レスポンスタイム** | 要求を出してから応答が返るまでの時間 |
| **ターンアラウンドタイム** | ジョブ投入から結果受取りまでの全時間 |
| **ベンチマーク** | 標準的なプログラムで性能を測定すること |
| **MIPS** | 1 秒間に実行できる命令数（百万単位） |
