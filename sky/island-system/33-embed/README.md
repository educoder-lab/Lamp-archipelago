# 講座 33　組込みとIoT

## 物語

系譜士セラが待っている。信頼性と冗長。システム全体の話。

## 分野

テクノロジ・システム構成

## 今日の用語

| 用語 | 意味 |
|------|------|
| **組込みシステム** | 特定の機能を実行するために機器に内蔵されたコンピュータシステム |
| **リアルタイム OS** | 応答時間が保証された OS。制御用途に使用 |
| **IoT** | あらゆるモノがインターネットにつながる概念 |
| **センサ** | 温度・圧力・光などの物理量を電気信号に変換する装置 |
| **アクチュエータ** | 電気信号を物理的な動き（モータなど）に変換する装置 |
