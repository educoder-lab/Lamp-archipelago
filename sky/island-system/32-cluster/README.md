# 講座 32　クラスタと負荷分散

## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **クラスタリング** | 複数のサーバをまとめて 1 台のように使う技術 |
| **ロードバランサ** | アクセスを複数サーバに振り分ける装置 |
| **スケールアウト** | サーバ台数を増やして処理能力を上げること |
| **スケールアップ** | サーバ自体の性能（CPU・メモリ）を上げること |
