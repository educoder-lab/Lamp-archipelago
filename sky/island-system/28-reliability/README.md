# 講座 28　システムの信頼性

## 物語

講座 **28** 系譜の館に「システムの信頼性」の封印がある。
信頼性の釣り合いが館を支える。系譜士セラ が待っている。

## 分野

テクノロジ・システム構成

## 今日の用語

| 用語 | 意味 |
|------|------|
| **MTBF（平均故障間隔）** | 故障と故障の間の平均稼働時間 |
| **MTTR（平均修復時間）** | 故障発生から復旧までの平均時間 |
| **稼働率** | MTBF / (MTBF + MTTR)。1 に近いほど高信頼 |
| **フェールセーフ** | 故障時に安全な状態に移行する設計思想 |
| **フォールトトレラント** | 故障が起きても運用を継続できる設計 |
