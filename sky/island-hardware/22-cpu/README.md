# 講座 22　CPU の仕組み

## 物語

講座 **22** 工房に「CPU の仕組み」の封印がある。
ハンマーの音がメモリの階層を思い出させる。工房長ガスト が待っている。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **CPU（中央処理装置）** | コンピュータの演算と制御を担う装置 |
| **レジスタ** | CPU 内部の高速な記憶領域 |
| **プログラムカウンタ** | 次に実行する命令のアドレスを保持するレジスタ |
| **クロック周波数** | CPU の動作速度。GHz 単位で表す |
| **命令サイクル** | 命令の取出し→解読→実行→書戻しの一連の流れ |
