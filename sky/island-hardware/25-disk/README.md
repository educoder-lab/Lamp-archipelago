# 講座 25　補助記憶と入出力

## 物語

講座 **25** 工房に「補助記憶と入出力」の封印がある。
ハンマーの音がメモリの階層を思い出させる。工房長ガスト が待っている。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **HDD** | 磁気ディスクで大容量データを保存する装置 |
| **SSD** | フラッシュメモリを使った高速な補助記憶装置 |
| **シーク時間** | 磁気ヘッドを目的トラックまで移動させる時間 |
| **フラグメンテーション** | ファイルがディスク上に断片化して散らばる現象 |
| **RAID** | 複数ディスクを組み合わせて信頼性・速度を向上させる技術 |
