# 講座 24　記憶装置の階層

## 物語

工房長ガストが待っている。蒸気と歯車。CPUと記憶の話。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **キャッシュメモリ** | CPU とメインメモリの間に置く高速小容量の記憶装置 |
| **メインメモリ (RAM)** | CPU が直接アクセスする主記憶。電源 OFF で消える |
| **ROM** | 読出し専用メモリ。電源 OFF でも内容が残る |
| **ヒット率** | キャッシュにデータがあった割合 |
| **実効アクセス時間** | ヒット率を加味した平均アクセス時間 |
