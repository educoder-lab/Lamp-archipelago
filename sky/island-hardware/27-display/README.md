# 講座 27　表示装置と解像度

## 物語

講座 **27** 工房に「表示装置と解像度」の封印がある。
ハンマーの音がメモリの階層を思い出させる。工房長ガスト が待っている。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **解像度** | 画面のピクセル数。1920×1080 など |
| **VRAM** | 画面表示用の専用メモリ。表示色数×解像度で必要量が決まる |
| **液晶ディスプレイ** | 液晶の光透過率を制御して表示する装置 |
| **有機 EL** | 有機化合物の発光を利用した自発光型ディスプレイ |
