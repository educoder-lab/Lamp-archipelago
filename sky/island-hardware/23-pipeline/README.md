# 講座 23　パイプラインと高速化

## 物語

講座 **23** 工房に「パイプラインと高速化」の封印がある。
ハンマーの音がメモリの階層を思い出させる。工房長ガスト が待っている。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **パイプライン処理** | 命令の各段階をずらして並行実行する高速化手法 |
| **パイプラインハザード** | データ依存や分岐で流れが停止する問題 |
| **スーパースカラ** | 複数のパイプラインで同時に命令を実行する方式 |
| **RISC** | 命令種類を少なく固定長にした CPU 設計。パイプライン向き |
| **CISC** | 命令種類が豊富で可変長の CPU 設計 |
