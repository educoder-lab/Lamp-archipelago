# 講座 26　入出力インタフェース

## 物語

工房長ガストが待っている。蒸気と歯車。CPUと記憶の話。

## 分野

テクノロジ・ハードウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **USB** | 周辺機器を接続する汎用シリアルバス |
| **HDMI** | 映像と音声をデジタルで送るインタフェース |
| **Bluetooth** | 近距離無線通信規格（数m〜数十m） |
| **DMA（ダイレクトメモリアクセス）** | CPU を介さず周辺機器とメモリ間でデータ転送する方式 |
