# 講座 65　知的財産と法務

## 物語

講座 **65** 港の帳場に「知的財産と法務」の封印がある。
船目が企業の物語を運ぶ。港の書記ホウ が待っている。

## 分野

ストラテジ・企業活動

## 今日の用語

| 用語 | 意味 |
|------|------|
| **著作権** | 創作物を保護する権利。登録不要で発生 |
| **特許権** | 発明を保護する権利。出願・審査が必要 |
| **商標権** | ブランドの名前やマークを保護する権利 |
| **不正競争防止法** | 営業秘密の不正取得などを禁じる法律 |
