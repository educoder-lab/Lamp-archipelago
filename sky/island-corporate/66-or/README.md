# 講座 66　OR・在庫管理

## 物語

港の書記ホウが待っている。企業と法務の港。

## 分野

ストラテジ・企業活動

## 今日の用語

| 用語 | 意味 |
|------|------|
| **線形計画法 (LP)** | 制約条件のもとで目的関数を最大化・最小化する手法 |
| **在庫管理（EOQ）** | 発注費と保管費の合計を最小にする経済的発注量 |
| **PERT** | 作業の依存関係をネットワーク図で表し最短工期を求める手法 |
| **クリティカルパス** | プロジェクト最短工期を決める最長経路 |
