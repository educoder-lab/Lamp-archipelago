# 講座 67　企業分析と標準化

## 物語

講座 **67** 港の帳場に「企業分析と標準化」の封印がある。
船目が企業の物語を運ぶ。港の書記ホウ が待っている。

## 分野

ストラテジ・企業活動

## 今日の用語

| 用語 | 意味 |
|------|------|
| **SWOT 分析** | 強み・弱み・機会・脅威で経営環境を分析するフレームワーク |
| **PPM（プロダクトポートフォリオマネジメント）** | 市場成長率と市場シェアで事業を分類する手法 |
| **BSC（バランススコアカード）** | 4 つの視点（財務・顧客・業務・学習）で経営を評価する手法 |
| **QC 七つ道具** | パレート図・特性要因図など品質管理に使う基本ツール群 |
