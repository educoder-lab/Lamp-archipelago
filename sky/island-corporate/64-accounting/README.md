# 講座 64　財務と会計の基礎

## 物語

講座 **64** 港の帳場に「財務と会計の基礎」の封印がある。
船目が企業の物語を運ぶ。港の書記ホウ が待っている。

## 分野

ストラテジ・企業活動

## 今日の用語

| 用語 | 意味 |
|------|------|
| **損益計算書（P/L）** | 一定期間の収益と費用から利益を示す書類 |
| **貸借対照表（B/S）** | ある時点の資産・負債・純資産を示す書類 |
| **売上総利益** | 売上高 − 売上原価 |
| **営業利益** | 売上総利益 − 販売費及び一般管理費 |
| **損益分岐点** | 売上高と費用が等しくなり利益ゼロとなる点 |
