## 今日の用語

| 用語 | 意味 |
|------|------|
| **ASCII** | 英数字・記号を 7 ビット（128 種）で表す文字コード |
| **Unicode** | 世界中の文字を統一的に扱う文字集合 |
| **UTF-8** | Unicode を可変長（1〜4 バイト）で符号化する方式。ASCII 互換 |
| **Shift_JIS** | 日本語を 1〜2 バイトで表す文字コード |
