## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ビット (bit)** | 情報の最小単位。0 か 1 の二択を 1 ビットと呼ぶ |
| **バイト (byte)** | 8 ビットをまとめた単位。1 バイト = 8 ビット |
| **ワード** | CPU が一度に扱うデータ幅。32 ビットや 64 ビットなど |
