# 講座 04　論理演算

## 物語

雲門に真理の表が浮かぶ。ANDとORが問いかける。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **AND（論理積）** | 両方 1 のとき結果が 1 |
| **OR（論理和）** | どちらか 1 なら結果が 1 |
| **NOT（否定）** | 0 と 1 を反転する |
| **XOR（排他的論理和）** | 値が異なるとき結果が 1 |
