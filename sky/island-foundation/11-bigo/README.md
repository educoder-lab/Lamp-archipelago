# 講座 11　計算量とオーダ

## 物語

塔の見上げる先で、計算量の神話が語られる。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **時間計算量** | アルゴリズムの実行ステップ数がデータ量でどう増えるか |
| **O 記法（ビッグオー）** | 計算量の上限を漸近的に表す表記。O(n), O(n²) など |
| **O(1)** | データ量に関係なく一定時間 |
| **O(n log n)** | 効率的なソートの典型的な計算量 |
