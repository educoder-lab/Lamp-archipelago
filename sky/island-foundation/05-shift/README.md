# 講座 05　シフト演算と補数

## 物語

灯芯をずらすと、数が別の姿を見せる。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **左シフト** | ビット列を左にずらす。1 回で値が 2 倍 |
| **右シフト** | ビット列を右にずらす。1 回で値が 1/2 |
| **2 の補数** | 負の数を表すための方法。全ビット反転＋1 |
| **算術シフト** | 符号ビットを保持したままシフトする操作 |
