## 今日の用語

| 用語 | 意味 |
|------|------|
| **有限オートマトン** | 状態と遷移で文字列の受理を判定する計算モデル |
| **正規表現** | 文字列パターンを記述する表記法 |
| **BNF 記法** | プログラミング言語の文法をルールで定義する記法 |
| **逆ポーランド記法** | 演算子を被演算子の後に書く。スタックで評価可能 |
