# 講座 06　浮動小数点と誤差

## 物語

水槽に丸い誤差の泡が浮かぶ。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **浮動小数点数** | 仮数部×基数の指数乗で実数を表す形式 |
| **IEEE 754** | 浮動小数点の国際標準。単精度(32ビット)・倍精度(64ビット) |
| **丸め誤差** | 有限桁で表せない値を丸めることで生じる誤差 |
| **桁落ち** | 近い値の引き算で有効桁数が減る現象 |
| **情報落ち** | 大きい値に小さい値を加えても反映されない現象 |
