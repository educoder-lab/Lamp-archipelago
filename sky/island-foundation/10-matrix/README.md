## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **行列** | 数を縦横に並べた配列。行(横)と列(縦)で位置を指定 |
| **単位行列** | 対角成分が 1、それ以外が 0 の正方行列 |
| **逆行列** | 元の行列と掛けると単位行列になる行列 |
