# 講座 08　集合と論理

## 物語

集合の輪が空中に重なる。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **和集合（A∪B）** | A か B の少なくとも一方に属する要素の集合 |
| **積集合（A∩B）** | A と B の両方に属する要素の集合 |
| **補集合** | 全体集合のうちその集合に属さない要素 |
| **ベン図** | 集合の関係を円の重なりで視覚化する図 |
