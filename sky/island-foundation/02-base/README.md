# 講座 02　基数変換

## 物語

銘板が2進と16進で刻まれている。読めば扉が開くという。

## 分野

テクノロジ・基礎理論

## 今日の用語

| 用語 | 意味 |
|------|------|
| **2 進数** | 0 と 1 だけで数を表す記数法 |
| **10 進数** | 日常で使う 0〜9 の記数法 |
| **16 進数** | 0〜9 と A〜F で表す記数法。4 ビットが 1 桁に対応 |
| **基数変換** | ある基数の数を別の基数に直すこと |
