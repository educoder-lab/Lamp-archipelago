## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **二分探索** | ソート済み配列の中央と比較して範囲を半分に絞る探索。O(log n) |
| **探索範囲** | 探索対象として残っている部分 |
| **前提条件** | 二分探索はデータが整列済みでなければならない |
