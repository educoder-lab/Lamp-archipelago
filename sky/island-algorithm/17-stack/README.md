# 講座 17　スタックとキュー

## 物語

時計塔の技師ミラが待っている。アルゴリズムとデータ構造の塔が並ぶ島。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **スタック** | 後入れ先出し (LIFO)。push で追加、pop で取出し |
| **キュー** | 先入れ先出し (FIFO)。enqueue で追加、dequeue で取出し |
| **オーバーフロー** | 容量を超えてデータを追加しようとするエラー |
| **アンダーフロー** | 空の構造からデータを取り出そうとするエラー |
