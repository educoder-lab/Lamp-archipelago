# 講座 20　ハッシュ法

## 物語

鍵穴の列に名前が吸い込まれていく。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ハッシュ法** | キーからハッシュ関数で格納位置を計算する方法。O(1)の探索 |
| **ハッシュ関数** | キーを配列の添字に変換する関数 |
| **衝突（コリジョン）** | 異なるキーが同じハッシュ値になること |
| **オープンアドレス法** | 衝突時に別の空き位置を探す方法 |
| **チェイン法** | 衝突時にリンクリストでつなげる方法 |
