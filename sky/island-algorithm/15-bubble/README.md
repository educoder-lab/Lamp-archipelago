# 講座 15　バブルソートと選択ソート

## 物語

時計塔の技師ミラが待っている。アルゴリズムとデータ構造の塔が並ぶ島。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **バブルソート** | 隣接要素を比較・交換して整列する。O(n²) |
| **選択ソート** | 未整列部分から最小値を選んで先頭に置く。O(n²) |
| **安定ソート** | 同値要素の相対順序が保たれるソート |
