# 講座 19　木構造と二分木

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **木（ツリー）** | 親子関係を持つ階層的なデータ構造 |
| **根（ルート）** | 木の最上位ノード |
| **葉（リーフ）** | 子を持たないノード |
| **二分探索木** | 左部分木 < 親 < 右部分木 の規則を持つ二分木 |
| **走査（トラバーサル）** | 木の全ノードを一定の順序で訪問すること |
