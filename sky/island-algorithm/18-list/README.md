# 講座 18　リスト構造

## 物語

鎖のようにつながったノードが空中に浮く。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **連結リスト** | 各要素がデータと次の要素へのポインタを持つ構造 |
| **単方向リスト** | 次の要素だけを指すリスト |
| **双方向リスト** | 前後両方の要素を指すリスト |
| **ポインタ** | メモリ上のアドレスを保持する変数 |
