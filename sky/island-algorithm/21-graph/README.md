# 講座 21　グラフと探索

## 物語

塔頂で頂点と辺が星のように広がる。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **グラフ** | 頂点（ノード）と辺（エッジ）で関係を表すデータ構造 |
| **有向グラフ** | 辺に方向があるグラフ |
| **深さ優先探索 (DFS)** | スタックを使い、行けるだけ深く探索してから戻る |
| **幅優先探索 (BFS)** | キューを使い、近い頂点から順に探索する |
