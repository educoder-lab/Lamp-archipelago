# 講座 16　マージソートとクイックソート

## 物語

二つの歯車列が合流する分岐点。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **マージソート** | 分割統治法で配列を半分ずつ分けて統合。O(n log n)・安定 |
| **クイックソート** | 基準値(ピボット)で分割を繰り返す。平均 O(n log n) |
| **分割統治法** | 問題を小さく分けて解き、結果を統合する手法 |
