# 講座 13　配列と線形探索

## 物語

塔の低層。棚に番号の付いた箱が並び、先頭から光が走る。

## 分野

テクノロジ・アルゴリズム

## 今日の用語

| 用語 | 意味 |
|------|------|
| **配列** | 同じ型のデータを連続して格納するデータ構造 |
| **添字（インデックス）** | 配列の要素位置を示す番号（0 始まりが多い） |
| **線形探索（逐次探索）** | 先頭から順に目的の値を探す方法。O(n) |
| **番兵法** | 末尾にダミーを置いて終了判定を省略する手法 |
