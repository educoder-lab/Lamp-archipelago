# 講座 38　コンパイラとリンカ

## 物語

講座 **38** 書庫に「コンパイラとリンカ」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **コンパイラ** | ソースコードを一括して機械語に翻訳するプログラム |
| **インタプリタ** | ソースコードを 1 行ずつ解釈・実行するプログラム |
| **リンカ** | オブジェクトファイルやライブラリを結合して実行ファイルを作る |
| **ローダ** | 実行ファイルをメモリに読み込んで実行準備をする |
