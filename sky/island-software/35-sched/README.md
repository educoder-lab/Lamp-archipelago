# 講座 35　スケジューリングと排他

## 物語

講座 **35** 書庫に「スケジューリングと排他」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ラウンドロビン** | 各プロセスに均等な CPU 時間（タイムスライス）を与える方式 |
| **優先度方式** | 優先度の高いプロセスから実行する方式 |
| **排他制御** | 共有資源に同時アクセスさせないための制御 |
| **デッドロック** | 互いに資源の解放を待ち合って処理が止まる状態 |
| **セマフォ** | 資源の利用可能数を管理し排他制御を実現する仕組み |
