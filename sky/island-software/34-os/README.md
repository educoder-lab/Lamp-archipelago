# 講座 34　OSの役割とプロセス

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **OS（オペレーティングシステム）** | ハードウェアを管理し、アプリに共通サービスを提供する基盤ソフト |
| **プロセス** | 実行中のプログラムの単位 |
| **スレッド** | プロセス内の実行単位。軽量プロセスとも呼ばれる |
| **マルチタスク** | 複数のタスクを切り替えて並行実行する仕組み |
| **カーネル** | OS の中核部分。資源管理や割込み処理を行う |
