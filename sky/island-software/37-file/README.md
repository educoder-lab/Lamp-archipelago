# 講座 37　ファイルシステム

## 物語

講座 **37** 書庫に「ファイルシステム」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ファイルシステム** | ファイルの保存・管理を行う OS の仕組み |
| **ディレクトリ（フォルダ）** | ファイルを階層的に整理する入れ物 |
| **絶対パス** | ルートからの完全な経路指定 |
| **相対パス** | 現在地からの経路指定 |
