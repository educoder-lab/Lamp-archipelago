# 講座 39　OSSとライセンス

## 物語

講座 **39** 書庫に「OSSとライセンス」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **OSS（オープンソースソフトウェア）** | ソースコードが公開され自由に利用・改変・再配布できるソフト |
| **GPL** | 改変物にも同じライセンスを要求するコピーレフト型ライセンス |
| **Apache License** | 制約が緩く商用利用しやすい OSS ライセンス |
| **Linux** | Unix 系の OSS カーネル |
