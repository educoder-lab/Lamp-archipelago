# 講座 39　OSSとライセンス

## 物語

講座 **39** 書庫に「OSSとライセンス」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **OSS（オープンソースソフトウェア）** | ソフトの中身（ソースコード＝設計図）が公開されていて、見て・直して・配ってよいソフト。ただし「どう使ってよいか」はライセンス（約束）で決まる |
| **ライセンス** | ソフトの使い方のルール。「改変してよいか」「配るときに何を守るか」などを書いた約束 |
| **GPL** | 約束がきついライセンス。改変した版を公開するときは、**同じ GPL** を付けないといけない（＝同じ条件を引き継ぐ） |
| **Apache License** | 約束がゆるいライセンス。会社の製品に組み込みやすい。改変版に別の約束を付けやすい |
| **Linux** | OSS の代表例。パソコンやサーバを動かす中核（カーネル）として広く使われている |

### たとえ（最初にこれだけ覚えれば十分）

- **OSS** … 料理のレシピが公開されている。見て真似して、アレンジして配ってよい
- **ライセンス** … そのレシピを配るときの注意書き
- **GPL** … 「アレンジしたレシピも、同じ注意書きを付けて公開してね」という厳しい注意書き
- **Apache** … 「わりと自由に使ってよい」ゆるい注意書き
- **Linux** … その公開レシピで作られた、よく知られた“厨房の心臓部”

### よくある誤解

OSS だからといって「タダ売り禁止」ではない。お金を取って配ることも、約束の範囲では許されることが多い。
