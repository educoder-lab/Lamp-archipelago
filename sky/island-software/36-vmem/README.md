# 講座 36　仮想記憶

## 物語

講座 **36** 書庫に「仮想記憶」の封印がある。
プロセスの足音が廊下に響く。書庫司書オウ が待っている。

## 分野

テクノロジ・ソフトウェア

## 今日の用語

| 用語 | 意味 |
|------|------|
| **仮想記憶** | 主記憶＋補助記憶で実際より大きなメモリ空間を実現する仕組み |
| **ページング** | 仮想空間を固定長のページに分割して管理する方式 |
| **ページフォールト** | 必要なページが主記憶にないとき発生する割込み |
| **LRU** | 最も長く使われていないページを置き換える方式 |
| **スラッシング** | ページ置換が頻発して処理が進まなくなる現象 |
