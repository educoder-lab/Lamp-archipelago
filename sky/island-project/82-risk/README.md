# 講座 82　リスクと品質管理

## 物語

講座 **82** 吊橋に「リスクと品質管理」の封印がある。
工数の風が橋を揺らす。吊橋番ケイ が待っている。

## 分野

マネジメント・プロジェクト管理

## 今日の用語

| 用語 | 意味 |
|------|------|
| **リスク管理** | リスクの特定・分析・対応策を計画する活動 |
| **リスク回避** | リスクの原因となる活動を取りやめること |
| **リスク転嫁** | 保険や外注によりリスクを第三者に移すこと |
| **EVM（アーンドバリューマネジメント）** | 出来高でコストとスケジュールの進捗を管理する手法 |
