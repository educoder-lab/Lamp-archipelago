# 講座 81　スケジュールと工数

## 物語

講座 **81** 吊橋に「スケジュールと工数」の封印がある。
工数の風が橋を揺らす。吊橋番ケイ が待っている。

## 分野

マネジメント・プロジェクト管理

## 今日の用語

| 用語 | 意味 |
|------|------|
| **クリティカルパス法 (CPM)** | 最長経路から最短工期を算出する手法 |
| **ファンクションポイント法 (FP)** | 機能数から工数を見積もる手法 |
| **COCOMO** | ソースコード行数から工数を推定するモデル |
| **アローダイアグラム** | 作業を矢印で表すネットワーク図 |
