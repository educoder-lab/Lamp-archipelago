# 講座 80　プロジェクト管理の基礎

## 物語

講座 **80** 吊橋に「プロジェクト管理の基礎」の封印がある。
工数の風が橋を揺らす。吊橋番ケイ が待っている。

## 分野

マネジメント・プロジェクト管理

## 今日の用語

| 用語 | 意味 |
|------|------|
| **プロジェクト** | 期限と目標が定まった一回限りの活動 |
| **PMBOK** | プロジェクト管理の知識体系。10 の知識エリア |
| **WBS（作業分解構成図）** | 成果物を階層的にタスクに分解する図 |
| **ガントチャート** | 横軸に時間、タスクの開始・終了を棒で示す図 |
| **マイルストーン** | プロジェクトの重要な節目 |
