# 講座 51　ルーティングとスイッチ

## 物語

講座 **51** 航路台に「ルーティングとスイッチ」の封印がある。
パケットの星が空図に並ぶ。航路司フェン が待っている。

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ルータ** | 異なるネットワーク間でパケットを転送する装置（L3） |
| **L2スイッチ（スイッチングハブ）** | MAC アドレスを基にフレームを転送する装置 |
| **デフォルトゲートウェイ** | 外部ネットワークへの出口となるルータの IP |
| **ルーティングテーブル** | パケットの転送先を管理する経路表 |
