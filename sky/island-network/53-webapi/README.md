# 講座 53　Webとプロトコル応用

## 物語

講座 **53** 航路台に「Webとプロトコル応用」の封印がある。
パケットの星が空図に並ぶ。航路司フェン が待っている。

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **URL** | Web 上のリソースの場所を示す文字列 |
| **Cookie** | Web サーバがブラウザに保存させる小さなデータ |
| **REST** | HTTP メソッド(GET/POST等)でリソースを操作する設計方式 |
| **プロキシサーバ** | クライアントの代理で外部にアクセスする中継サーバ |
