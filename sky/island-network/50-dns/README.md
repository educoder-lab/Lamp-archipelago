# 講座 50　DNS・DHCP・メール

## 物語

航路司フェンが待っている。プロトコルの風路。

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **DNS** | ドメイン名を IP アドレスに変換するシステム |
| **DHCP** | IP アドレスを自動的に割り当てるプロトコル |
| **SMTP** | メール送信に使うプロトコル（ポート 25） |
| **POP3/IMAP** | メール受信に使うプロトコル |
