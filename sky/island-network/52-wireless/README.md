# 講座 52　無線LANとHTTP

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **無線 LAN (Wi-Fi)** | 電波を使ったローカルエリアネットワーク。IEEE 802.11 規格 |
| **SSID** | 無線 LAN のネットワーク名 |
| **WPA2/WPA3** | 無線 LAN の暗号化規格 |
| **HTTP/HTTPS** | Web ページの取得に使うプロトコル。S は SSL/TLS で暗号化 |
