# 講座 49　TCP/UDPとポート

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **TCP** | コネクション型の信頼性ある通信プロトコル |
| **UDP** | コネクションレス型の高速だが信頼性を保証しないプロトコル |
| **ポート番号** | アプリケーションを識別する 0〜65535 の番号 |
| **3ウェイハンドシェイク** | TCP 接続確立時の SYN→SYN+ACK→ACK のやり取り |
