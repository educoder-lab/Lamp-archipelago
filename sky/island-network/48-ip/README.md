# 講座 48　IPアドレスとサブネット

## 物語

講座 **48** 航路台に「IPアドレスとサブネット」の封印がある。
パケットの星が空図に並ぶ。航路司フェン が待っている。

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **IPv4** | 32 ビットのアドレス。約 43 億個 |
| **IPv6** | 128 ビットのアドレス。事実上無限 |
| **サブネットマスク** | ネットワーク部とホスト部を区別するためのビットマスク |
| **CIDR** | クラスに依存しない柔軟なアドレス割当て方式 |
| **NAT** | プライベート IP とグローバル IP を変換する技術 |
