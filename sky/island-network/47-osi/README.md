# 講座 47　OSI参照モデル

## 物語

講座 **47** 航路台に「OSI参照モデル」の封印がある。
パケットの星が空図に並ぶ。航路司フェン が待っている。

## 分野

テクノロジ・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **OSI 参照モデル** | ネットワーク通信を 7 階層に分けた標準モデル |
| **物理層** | 電気信号やケーブルなどの物理的な伝送 |
| **データリンク層** | 同一ネットワーク内のフレーム伝送。MAC アドレスを使用 |
| **ネットワーク層** | 異なるネットワーク間のルーティング。IP アドレスを使用 |
| **トランスポート層** | 端末間の信頼性ある通信。TCP/UDP を使用 |
