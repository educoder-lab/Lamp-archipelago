# 講座 77　テスト技法

## 物語

講座 **77** 開発工房に「テスト技法」の封印がある。
UMLの線が壁に浮かぶ。工房棟梁ディン が待っている。

## 分野

マネジメント・開発技術

## 今日の用語

| 用語 | 意味 |
|------|------|
| **単体テスト** | モジュール単位で動作を確認するテスト |
| **結合テスト** | モジュール間の連携を確認するテスト |
| **システムテスト** | システム全体が要件を満たすかを確認するテスト |
| **ホワイトボックステスト** | 内部構造（コード）を基にテストケースを作成する手法 |
| **ブラックボックステスト** | 仕様を基に入出力をテストする手法 |
