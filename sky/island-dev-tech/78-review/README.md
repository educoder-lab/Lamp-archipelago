# 講座 78　レビューと品質管理

## 物語

UMLの線が壁に浮かぶ。工房棟梁ディン が待っている。

## 分野

マネジメント・開発技術

## 今日の用語

| 用語 | 意味 |
|------|------|
| **デザインレビュー** | 設計書を関係者が確認して問題を指摘する活動 |
| **ウォークスルー** | 作成者が資料を説明しながらレビューする方法 |
| **インスペクション** | 第三者が公式な手順で欠陥を検出するレビュー |
| **回帰テスト（リグレッションテスト）** | 修正後に他の箇所に影響がないか確認するテスト |
