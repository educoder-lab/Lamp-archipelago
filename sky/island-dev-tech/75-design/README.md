# 講座 75　設計手法とUML

## 物語

工房棟梁ディンが待っている。開発の型と技術。

## 分野

マネジメント・開発技術

## 今日の用語

| 用語 | 意味 |
|------|------|
| **外部設計（基本設計）** | 画面・帳票・インタフェースなどユーザ視点の設計 |
| **内部設計（詳細設計）** | モジュール構造やデータ構造の設計 |
| **UML** | オブジェクト指向の統一モデリング言語。クラス図・ユースケース図等 |
| **クラス図** | クラスの属性・操作・関連を表す UML 図 |
| **モジュール結合度・凝集度** | 結合度は低いほど、凝集度は高いほど良い設計 |
