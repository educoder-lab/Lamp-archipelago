## 今日の用語

| 用語 | 意味 |
|------|------|
| **カプセル化** | データと操作をまとめ外部から隠蔽する概念 |
| **継承（インヘリタンス）** | 既存クラスの性質を引き継いで新クラスを作ること |
| **多態性（ポリモーフィズム）** | 同じメッセージで異なる動作をする性質 |
| **抽象クラス** | インスタンス化できない、派生クラスの雛形となるクラス |
| **インタフェース** | 実装を持たず、メソッドの仕様のみを定義する型 |
