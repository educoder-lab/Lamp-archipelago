# 講座 79　運用・保守とDevOps

## 物語

講座 **79** 開発工房に「運用・保守とDevOps」の封印がある。
UMLの線が壁に浮かぶ。工房棟梁ディン が待っている。

## 分野

マネジメント・開発技術

## 今日の用語

| 用語 | 意味 |
|------|------|
| **保守** | リリース後の不具合修正や機能追加を行う活動 |
| **DevOps** | 開発と運用を一体化して迅速にリリースする文化と手法 |
| **CI/CD** | 継続的インテグレーション / 継続的デリバリの略 |
| **リファクタリング** | 外部動作を変えずにコードの内部構造を改善すること |
