# 講座 74　開発プロセスモデル

## 物語

工房棟梁ディンが待っている。開発の型と技術。

## 分野

マネジメント・開発技術

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ウォーターフォールモデル** | 要件定義→設計→実装→テストを順に進める開発モデル |
| **アジャイル開発** | 短いイテレーションで機能を繰り返し開発する手法 |
| **スクラム** | アジャイルの代表的なフレームワーク。スプリント単位で開発 |
| **プロトタイピング** | 試作品を作りユーザの確認を得ながら進める手法 |
| **スパイラルモデル** | プロトタイプ＋リスク分析を繰り返す開発モデル |
