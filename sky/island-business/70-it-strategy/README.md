# 講座 70　IT戦略とガバナンス

## 分野

ストラテジ・経営戦略

## 今日の用語

| 用語 | 意味 |
|------|------|
| **IT ガバナンス** | 経営戦略に沿って IT を統制する仕組み |
| **BPR（ビジネスプロセスリエンジニアリング）** | 業務プロセスを抜本的に再設計すること |
| **ERP** | 企業資源を統合管理する基幹業務システム |
| **SoR / SoE** | 記録のシステム（安定重視）と関与のシステム（変化対応） |
