# 講座 71　システム調達と契約

## 物語

講座 **71** 羅針盤室に「システム調達と契約」の封印がある。
経営の風が帆を張る。羅針盤の執事アル が待っている。

## 分野

ストラテジ・経営戦略

## 今日の用語

| 用語 | 意味 |
|------|------|
| **RFP（提案依頼書）** | ベンダに提案を依頼する文書。要件・条件を記載 |
| **RFI（情報提供依頼書）** | ベンダに技術情報や実績を問い合わせる文書 |
| **SLA（サービスレベル合意書）** | サービス品質の合意事項を定めた文書 |
| **請負契約** | 成果物の完成を約束する契約。瑕疵担保責任あり |
| **準委任契約** | 業務遂行を委託する契約。成果物の完成義務なし |
