# 講座 69　マーケティングとe-Biz

## 物語

講座 **69** 羅針盤室に「マーケティングとe-Biz」の封印がある。
経営の風が帆を張る。羅針盤の執事アル が待っている。

## 分野

ストラテジ・経営戦略

## 今日の用語

| 用語 | 意味 |
|------|------|
| **マーケティングミックス (4P)** | 製品・価格・流通・販促で戦略を立てるフレームワーク |
| **CRM** | 顧客情報を管理して関係を強化する手法 |
| **SCM** | 調達から販売までの供給連鎖を最適化する管理手法 |
| **EC（電子商取引）** | インターネットを通じた商品・サービスの取引 |
| **SEO** | 検索エンジンで上位表示させる施策 |
