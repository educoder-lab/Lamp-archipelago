# 解説スライド スキーマ（Phase S · 超初心者版）

**目的**: 「パソコンをほとんど触ったことがない人」でも、1 枚ずつわかる。  
**表示**: `docs/lesson.html` → `docs/lamp-slides.js`

## 置き場所

| パス | 役割 |
|------|------|
| `_tools/slides/<domain>.json` | **手書きソース** ← ここを編集 |
| `docs/data/slides/<講座#>.json` | ビルド生成（手編集しない） |

```json
{
  "domain": "island-foundation",
  "lessons": {
    "1": { "slides": [ /* … */ ] }
  }
}
```

## 超初心者ルール（最重要）

1. **1 枚 = 1 こと**。1 枚に概念を 2 つ入れない。
2. **本文は短く**。1 枚の文字（全ブロック合計）は **80 字以内**を目標（上限 120 字）。
3. **ブロックは最大 2 個**（表紙は 0 個可）。`p` + `analogy` + `flow` を同じ枚に並べない。
4. **大事な言葉だけ強調**。`**太字**` か `==下線ハイライト==` を 1 枚に 1〜2 か所。
5. **むずかしい言葉の直後に、かんたんな言い換え**（括弧でもよい）。
6. **たとえ話を先に**。IT の定義だけから始めない。
7. **図を優先**。長い文章より `big` / `analogy` / `flow` / `bits` / `layers`。
8. 日本語は「です・ます」。子どもっぽくしすぎない。
9. **封印の問いの答えを書かない**。`check` は PROBLEMS と別の題材。
10. README・PROBLEMS と矛盾させない。

### 悪い例 → 良い例

```
❌ 1 枚に「たとえ + 定義 + 表 + 手順」を全部入れる
⭕ たとえだけの枚 → 定義だけの枚 → 図だけの枚 → 手順だけの枚
```

```
❌ 「コンピュータの部品は電気が流れている／いないの2状態で動き、これを1と0と呼び情報の最小単位であるビットと定義します」
⭕ 「**ビット**は、スイッチ 1 個です。」＋ 図
```

## 1 講座の組み立て（推奨 **10〜14 枚**）

| # | 内容 | ブロック例 |
|---|------|-----------|
| 1 | 表紙 | `layout:"title"`、短い subtitle |
| 2 | 身近なたとえだけ | `analogy` のみ |
| 3〜 | **1 キーワード = 1 枚** | `big` または `p`（短い）＋ 図 1 つ |
| … | 手順は **1 ステップ 1 枚**でも可 | `steps` は 3 項目まで／`trace` は単独 |
| … | まちがえやすい点 | `callout` `warn` のみ |
| … | 試験の型 | `callout` `exam` のみ |
| … | ミニ確認 | `check` **1 問だけ**（2 問なら 2 枚） |
| 最後 | まとめ（3 行以内） | `bullets` または `big` |

## スライド・ブロック

| フィールド | 必須 | 説明 |
|------------|------|------|
| `layout` | | `"title"` = 表紙 |
| `emoji` | | 見出しの絵文字 |
| `title` | ✓ | **短く**（問いかけ・日常語） |
| `subtitle` | | 表紙のみ。1 行 |
| `blocks` | ✓* | **最大 2**（表紙は空可） |
| `note` | | 任意。短く |

ブロック種別は従来どおり（`p` `bullets` `big` `analogy` `flow` `compare` `table` `cards` `callout` `code` `bits` `trace` `check` `layers` `steps` `array` `tree`）。詳細は `_tools/slides/island-foundation.json` の講座 1・2 を見本にする。

```json
  ]

```
