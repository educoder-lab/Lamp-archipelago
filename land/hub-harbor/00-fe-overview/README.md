## 学習プリント — 基本情報技術者試験（FE）の概要

### 試験の二本柱

| 区分 | 形式のイメージ | このマップ |
|------|----------------|------------|
| **午前** | 知識の四肢択一 | **空**の諸島 |
| **午後** | 読解・アルゴリズム追跡・記述 | **地下**の砦 |
| **総仕上げ** | 本番に近い総合 | **陸地**の台地 |

### 学び方

1. スライドでたとえと図から理解する  
2. このプリントで対応表を見返す  
3. 封印の問いで確認する（合格で港の灯が安定）

詳細な用語は各島の README と用語図鑑へ。
