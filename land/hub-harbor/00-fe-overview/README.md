## 学習プリント — 基本情報技術者試験（FE）の概要

現行の FE は **CBT・通年実施**です。試験区分の呼び方は **科目A試験／科目B試験**（旧称の「午前／午後」ではありません）。

### 試験の二本柱

| 区分 | 形式（現行） | このマップ |
|------|--------------|------------|
| **科目A** | 四肢択一・60問・90分 | **空**の諸島 |
| **科目B** | 多肢選択の小問・20問・100分（擬似言語・セキュリティ中心） | **地下**の砦 |
| **総仕上げ** | 本番に近い総合演習 | **陸地**の台地 |

### 科目Aで問われやすいもの（例）

- 基礎理論（ビット、論理、データ構造の入口）
- ハードウェア／ソフトウェア／ネットワーク／セキュリティの用語
- マネジメント・ストラテジの入口

### 科目Bで問われやすいもの（例）

- 擬似言語のトレース（値の変化を追う）
- 情報セキュリティ
- アルゴリズム・データ構造に関する小問（個別言語の大問は現行では出ません）

### 旅の進め方

1. 港から **空** または **地下** へ出発する  
2. 各土地では **灯を点けると次の島／砦へ**進める（霧の土地には入れない）  
3. **陸地**は、空の関門と地下の最深部がすべて灯ってから開く  

### 学び方

1. スライドでたとえと図から理解する  
2. このプリントで対応表を見返す  
3. 封印の問いで確認する（合格で港の灯が安定）

詳細な用語は各島の README と用語図鑑へ。
