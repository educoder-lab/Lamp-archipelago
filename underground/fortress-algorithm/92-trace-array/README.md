## 物語

## 分野

## 今日の用語

| 用語 | 意味 |
|------|------|
| **配列の添字** | 要素位置を示す番号。擬似言語では 1 始まりが多い |
| **配列の走査** | 配列の全要素を順に処理すること |
| **番兵** | 配列末尾にダミー値を置いて探索の終了判定を簡略化する手法 |
