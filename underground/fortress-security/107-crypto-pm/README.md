# 講座 107　暗号と認証の午後対策

## 物語

地下の盾壁団詰所。リスクと証跡の訓練──**暗号と認証の午後対策**。
衛兵の足音と、石が擦れる音。盾壁団リーゼ が石版を指さす。

## 分野

午後・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **ハイブリッド暗号** | 共通鍵暗号で本文を、公開鍵暗号で共通鍵を暗号化する方式 |
| **メッセージ認証コード (MAC)** | 通信内容の改ざんを検出するための認証データ |
| **タイムスタンプ** | データの存在時刻を第三者が証明する仕組み |
