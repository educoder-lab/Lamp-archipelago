# 講座 109　セキュア設計とゼロトラスト

## 物語

地下の盾壁団詰所。リスクと証跡の訓練──**セキュア設計とゼロトラスト**。
衛兵の足音と、石が擦れる音。盾壁団リーゼ が石版を指さす。

## 分野

午後・セキュリティ

## 今日の用語

| 用語 | 意味 |
|------|------|
| **セキュアバイデザイン** | 設計段階からセキュリティを組み込む考え方 |
| **ゼロトラスト** | 内部外部を問わずすべてのアクセスを検証するセキュリティモデル |
| **最小権限の原則** | 必要最小限のアクセス権だけを与える原則 |
