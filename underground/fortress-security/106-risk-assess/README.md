# 講座 106　リスクアセスメント演習

## 物語

地下の盾壁団詰所。リスクと証跡の訓練──**リスクアセスメント演習**。
衛兵の足音と、石が擦れる音。盾壁団リーゼ が石版を指さす。

## 分野

午後・セキュリティ

| 用語 | 意味 |
|------|------|
| **リスク値** | 脅威×脆弱性×資産価値で算出される指標 |
