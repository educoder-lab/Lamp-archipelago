# 講座 110　長文読解の技法

## 物語

地下の深層読書室。長文と戦略の訓練──**長文読解の技法**。
衛兵の足音と、石が擦れる音。深層司祭オーレ が石版を指さす。

## 分野

午後・総合読解

## 今日の用語

| 用語 | 意味 |
|------|------|
| **午後問題の構造** | 問題文（状況説明）→設問→選択肢の形式 |
| **下線部参照** | 設問が指す本文中の該当箇所を正確に特定する技術 |
| **消去法** | 明らかに誤りの選択肢を除外して正答を絞る技法 |
