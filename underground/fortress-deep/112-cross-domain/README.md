# 講座 112　分野横断演習

## 物語

地下の深層読書室。長文と戦略の訓練──**分野横断演習**。
衛兵の足音と、石が擦れる音。深層司祭オーレ が石版を指さす。

## 分野

科目B・総合読解

## 今日の用語

| 用語 | 意味 |
|------|------|
| **分野横断問題** | セキュリティ＋ネットワーク等、複数分野にまたがる問題 |
| **情報の関連付け** | 問題文中の異なる箇所の情報を結びつけて推論する技術 |
| **時間配分** | 科目B試験で各問題に適切な時間を割り当てる戦略 |
