# 講座 113　総合戦略と時間管理

## 物語

地下の深層読書室。長文と戦略の訓練──**総合戦略と時間管理**。
衛兵の足音と、石が擦れる音。深層司祭オーレ が石版を指さす。

## 分野

午後・総合読解

## 今日の用語

| 用語 | 意味 |
|------|------|
| **試験戦略** | 出題傾向と自分の得意分野を踏まえた解答順序の計画 |
| **得点最大化** | 確実に取れる問題を先に解き、難問は後回しにする戦略 |
| **見直し** | 解答後にケアレスミスや読み違いがないか確認する作業 |
