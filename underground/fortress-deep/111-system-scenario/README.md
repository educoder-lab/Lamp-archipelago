# 講座 111　システム構成シナリオ

## 物語

地下の深層読書室。長文と戦略の訓練──**システム構成シナリオ**。
衛兵の足音と、石が擦れる音。深層司祭オーレ が石版を指さす。

## 分野

午後・総合読解

## 今日の用語

| 用語 | 意味 |
|------|------|
| **午後シナリオ問題** | 具体的な業務シナリオを読み解いて解答する問題形式 |
| **要件の読み取り** | 問題文から機能要件・非機能要件を抽出する技術 |
| **表・図の読解** | ネットワーク構成図やテーブル定義から情報を読み取る技術 |
