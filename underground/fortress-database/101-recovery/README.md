# 講座 101　障害回復と性能

## 物語

地下の地下水晶庫。ERとSQLの訓練──**障害回復と性能**。
衛兵の足音と、石が擦れる音。水晶管理人ダリア が石版を指さす。

## 分野

科目B・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **チェックポイント** | ある時点でメモリ上のデータをディスクに書き出すこと |
| **ロールフォワード** | チェックポイント以降のログを使って最新状態に復元する操作 |
| **インデックス** | 検索を高速化するためのデータ構造（B 木など） |
| **B 木** | バランスの取れた多分岐木。データベースのインデックスに使用 |
