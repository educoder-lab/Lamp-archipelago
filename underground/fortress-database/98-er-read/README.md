## 今日の用語

| 用語 | 意味 |
|------|------|
| **E-R 図の読み方** | エンティティ間の多重度（1:N, M:N）を正しく読む |
| **連関エンティティ** | M:N 関連を解消するために追加する中間エンティティ |
| **属性の導出** | E-R図とテーブル定義から適切な列を特定する技法 |
