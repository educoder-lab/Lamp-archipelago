# 講座 100　ロックと同時実行制御

## 分野

午後・データベース

## 今日の用語

| 用語 | 意味 |
|------|------|
| **排他ロック** | 他のトランザクションの読書きを禁止するロック |
| **共有ロック** | 他のトランザクションの読みは許可し書きを禁止するロック |
| **2相ロック** | ロック取得フェーズと解放フェーズを分ける方式 |
| **楽観的ロック** | 更新時に競合を検出する方式。バージョン番号で管理 |
