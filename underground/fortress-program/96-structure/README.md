## 今日の用語

| 用語 | 意味 |
|------|------|
| **順次** | 上から順に処理を実行する構造 |
| **選択** | 条件に応じて処理を分岐させる構造 |
| **繰返し** | 条件が成立する間処理を繰り返す構造 |
| **構造化定理** | あらゆるアルゴリズムは順次・選択・繰返しの組合せで表現できる |
