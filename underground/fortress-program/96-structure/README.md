# 講座 96　制御構造の組合せ

## 物語

地下の擬似言語工房。石版コードの訓練──**制御構造の組合せ**。
衛兵の足音と、石が擦れる音。工房技師ザイン が石版を指さす。

## 分野

午後・プログラミング

## 今日の用語

| 用語 | 意味 |
|------|------|
| **順次** | 上から順に処理を実行する構造 |
| **選択** | 条件に応じて処理を分岐させる構造 |
| **繰返し** | 条件が成立する間処理を繰り返す構造 |
| **構造化定理** | あらゆるアルゴリズムは順次・選択・繰返しの組合せで表現できる |
