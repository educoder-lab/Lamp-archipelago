# 講座 97　デバッグと穴埋め対策

## 物語

地下の擬似言語工房。石版コードの訓練──**デバッグと穴埋め対策**。
衛兵の足音と、石が擦れる音。工房技師ザイン が石版を指さす。

## 分野

午後・プログラミング

## 今日の用語

| 用語 | 意味 |
|------|------|
| **デバッグ** | プログラムの誤り（バグ）を発見して修正する作業 |
| **ステップ実行** | 1 行ずつ実行して動作を確認するデバッグ手法 |
| **穴埋め問題** | 擬似言語の空欄に正しいコードを選ぶ午後の出題形式 |
| **境界値** | ループや条件分岐の境界でバグが起きやすい値 |
