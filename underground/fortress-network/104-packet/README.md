# 講座 104　パケット解析と通信制御

## 物語

伏線番エルクが待っている。サブネットと設計の要塞。

## 分野

午後・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **パケットキャプチャ** | ネットワーク上のパケットを取得して分析する手法 |
| **ARP** | IP アドレスから MAC アドレスを取得するプロトコル |
| **ICMP** | ネットワーク診断用のプロトコル（ping が使用） |
| **フロー制御** | 受信側の処理能力に合わせて送信量を調整する仕組み |
