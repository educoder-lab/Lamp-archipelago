# 講座 105　ネットワーク設計と冗長化

## 物語

地下の伏線要塞。配線と設計の訓練──**ネットワーク設計と冗長化**。
衛兵の足音と、石が擦れる音。伏線番エルク が石版を指さす。

## 分野

科目B・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **冗長構成** | 障害に備えて経路や機器を二重化する設計 |
| **STP（スパニングツリー）** | ループを防止する L2 プロトコル |
| **帯域計算** | 通信容量（bps）とデータ量から転送時間を求める計算 |
| **QoS（サービス品質）** | 通信の優先度を制御して品質を保証する技術 |
