# 講座 102　サブネット計算

## 物語

地下の伏線要塞。配線と設計の訓練──**サブネット計算**。
衛兵の足音と、石が擦れる音。伏線番エルク が石版を指さす。

## 分野

午後・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **CIDR 表記** | /24 のようにネットワーク部のビット数を表す記法 |
| **ホスト数の計算** | 2^(ホスト部ビット数) − 2（ネットワーク・ブロードキャスト除外） |
| **ネットワークアドレス** | ホスト部がすべて 0 のアドレス |
| **ブロードキャストアドレス** | ホスト部がすべて 1 のアドレス |
