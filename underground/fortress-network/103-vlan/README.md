# 講座 103　VLANとVPN

## 分野

午後・ネットワーク

## 今日の用語

| 用語 | 意味 |
|------|------|
| **VLAN** | 物理的な接続に関係なく論理的にネットワークを分割する技術 |
| **VPN** | 暗号化トンネルで安全な通信を実現する仮想プライベートネットワーク |
| **IPsec** | IP レベルで暗号化・認証を行うプロトコル群 |
| **SSL-VPN** | SSL/TLS を利用した VPN。ブラウザで利用可能 |
