## 構図ロック

拠点・道中のプレイ画面は常に同じ構図です。

1. 手前中央 … 主人公の**後ろ姿**
2. 正面奥 … **大扉**と**謎の老人**
3. 左 … 盾の道の入口
4. 右 … 剣の道の入口

俯瞰のワールドマップは**別画面**（`assets/map/`）。プレイ視点に混ぜない。
