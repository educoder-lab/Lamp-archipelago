# docs（ワールドマップ）

| 開き方 | URL |
|--------|-----|
| **Vercel**（Private リポジトリ向け） | Import 後 `https://<project>.vercel.app/map.html`（ルートの `vercel.json`） |
| **GitHub Pages**（Public 向け） | `https://educoder-lab.github.io/Lamp-archipelago/map.html` |
| **ローカル（進捗つき）** | リポジトリルートで `.\Show-Map.ps1` |

`map.html` は `Build-AllLessons.ps1` で再生成されます。個人の灯・迂回記録は `save-data.js`（git 管理外）に同期します。
